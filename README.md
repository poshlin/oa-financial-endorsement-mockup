## 🔴 紅線

1. **推薦語一字不改、不節錄、不潤飾。** 未經本人確認的內容不得以實線卡呈現
   （未確認請掛 `.endorse.is-draft`，珊瑚色虛線框）。
2. **不使用任何學校校徽或系徽。** 校徽會被家長讀成「學校認證這門課」，
   但事實是「學者個人具名推薦」＋「一件已結案的產學合作專案」，主體不同。
   校名以文字陳述是事實陳述，可以；使用機構標識不行。
   （北商大秘書室僅有「已註冊 7 類商標」宣示頁，無對外授權條款；要用必須先取得授權。）
3. **產學合作專案不得宣稱產出本課程。** 專案名稱寫的是「青少年」，本課程是國小 3-6 年級。
4. **robots 永遠是 `noindex, nofollow`**，不得改動。
5. **不要拿這個 repo 去部署。** 正式頁面在 `OrangeApple-Lab/oa-page-course-financial`。
