# 財商課程頁 — 學者推薦洽談用版本

🔴 **這不是正式頁面，也永遠不會變成正式頁面。**

## 這是什麼

`orangeapple.co/courses/financial/` 的一份複製，額外加了一個**空白的學者推薦版位**，
用途是與合作學者洽談掛名推薦時，展示「推薦區塊會長在哪裡、旁邊有什麼內容」。

建立於 2026-09-04，**溝通完成後整個 repo 刪除**。

## 與正式頁面的差異（只有三處）

| | 正式頁面 | 本版本 |
|---|---|---|
| robots | `index, follow, max-image-preview:large, max-snippet:-1` | **`noindex, nofollow`** |
| 頁首 | 無 | 多一條「此為洽談用版本」提示條 |
| 07 與 08 之間 | 無 | 多一個 `#endorsement` 空白推薦版位 |

其餘內容、文案、schema 與正式頁面完全相同。

## 🔴 紅線

1. **推薦版位一律留空。** 不得填入任何未經學者本人確認的姓名、頭銜、照片或推薦語。
   空框是「這裡留給您」，填了假內容就變成偽造背書——被截圖轉傳會出事。
2. **robots 永遠是 `noindex, nofollow`**，不得改動。
3. **不要拿這個 repo 去部署。** 正式頁面在 `OrangeApple-Lab/oa-page-course-financial`。
4. 學者同意之後，真實內容要加進**正式 repo**，不是這裡。
